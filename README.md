# GEGANTERS 3D: La Cercavila (Versió Sense Instal·lació / Zero-Build)

Aquesta versió utilitza **ES Modules natius del navegador (`importmap`)**, de manera que **no necessita Node.js, ni `npm install`, ni compilar res**.

## Com obrir-lo a Visual Studio Code sense instal·lar res

1. Descomprimeix aquesta carpeta i obre-la a **Visual Studio Code**.
2. Fes clic dret sobre `index.html` i tria **Open with Live Server** (o qualsevol servidor estàtic local).
3. També pots pujar aquesta carpeta directament al teu repositori de **GitHub Pages** i funcionarà a l'instant sense cap pas de *build*.
